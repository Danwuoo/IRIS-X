# Engineering Trials

This directory contains the tracked P2 admission package and is reserved for
future real Engineering Trials. No real domain, workload, provider/model,
backend, or budget is selected. The synthetic qualification fixture generated
under `.irisx/` is not a real trial and is not retained here.

[`p2-admission/`](p2-admission/) is a decision package, not trial results. It
records the blocked state, required owner choices, first-trial draft,
acceptance criteria, falsifiers, and Unknown fields. A real trial directory may
be created only after a later current decision admits it.

When separately authorized, each real trial must record its goal, baseline,
candidate intervention, workload, measured result, relevant costs, and
resulting engineering decision.
