From the repository, supply the local verified rebuild location. Output must
be a **new** descendant of `.irisx/run008-packaging`:

```sh

overlays="$PWD/tools/arc_qwen_rlvr004_20261013/loader_repair_run008/OVERLAY-MANIFEST.json"

  --repository-root "$PWD" \
  --candidate-root "$rebuild/candidate-rebuild" \
  --source-proposal-root "$rebuild/source-rebuild" \
  --rebuild-report "$rebuild/REBUILD-REPORT.json" \
  --overlay-manifest "$overlays" \
  --overlay-manifest-sha "$(sha256sum "$overlays" | cut -d' ' -f1)" \
  --output-root "$PWD/.irisx/run008-packaging/run008-proposal"
```

review of those final bytes.
