# True-ARC transfer runtime

This new namespace preserves the delivered source namespaces byte-for-byte.
The production run uses the exact old32 training parents, genuine demonstration
LOO targets, eight D4/background-fixed palette views and native PEFT SFT256.
The original family-balanced sampler is configured with one grid objective and
one family per parent; every complete update is physically metered.

Metadata-only SHA selection fixes new-to-this-Qwen-experiment dev16 and holdout32
before source task reads. Old24, exposed4 and pinned PUBLIC120 ancestor IDs and
known demo-only variants are excluded. No project-wide or pretraining-cleanliness
claim is made. Every original training-file test field is discarded. The last
training demonstration is the evaluation pseudo-query; its output goes only to
its scope's escrow. Dev and holdout escrow files are separate. Holdout scoring
is outside the model process, after owner closure and matching prediction seal.

Full demonstrations are packed using exact native template/token IDs. Training
starts from an immutable independently validated full LOO source record and
prepares packed context without truncating its target. Any parent with no
admissible full target causes the fixed main experiment to stop without a
replacement. Missing predictions always remain in the original denominator.

Base, SFT64 and SFT256 are observed on dev16. Both trained global checkpoints
are saved and actually loaded into newly constructed Qwen/PEFT backends with
identical source/config/optimizer/sampler/RNG state checks and monotone physical
counters. Base and the dev-selected *trained* SFT are compared on holdout32.

PUBLIC120 is an optional complete334-generation branch. Its separate frozen
dev selection includes base/SFT64/SFT256, uses the same exact→shape→valid→earlier
update ranking and reserves up to two additional fresh loads. It admits only
when the full panel and closure reserve fit. Its sole method uses identity and
one fixed D4 inverse. Answers and source-bound native evidence are sealed before
model-owner closure; an isolated outer CPU bridge uses the unchanged original
scorer. No public target selects methods, checkpoints or answers.

Only after these main results does optional TTT run on the fixed dev8+holdout8.
It admits the entire subexperiment or records TTT_NOT_RUN. For D visible demos
across N=16 parents it reserves 16*(D+N) updates,3D fold generations,3D likelihood
scores and6N final query generations. Each outer fold trains on every other
visible demonstration, including a legitimate zero-context supervised pair
when one example remains. Each candidate0/8/16 gets complete fold evidence;
the final query uses an independent full-demo refit. All task resets retain
selected-global-SFT identity. No per-task full optimizer archive is saved,
except the single preregistered representative. Every selector input and reset
receipt remains in the evidence archive. Per-method generation quotas are
fixed; extra TTT work is not presented as a compute-matched comparison.

The original owned process guard and safe pickle-free checkpoint format are
reused. Global budget43200, execution cutoff42000, provider cap42300 are
measured from the same explicit pre-dispatch epoch. No clock resets. Streamed
exports check the cutoff between each1MiB chunk and preserve failure outcomes.
Checkpoint tensors are separate from bounded evidence.zip; compact copies of
all global manifests/resume metadata are included for downstream validation.

CPU fixtures require explicit tiny random native-Qwen weights and never claim
14B/GPU effectiveness. An explicitly shortened128/512 calibration is supported
only on CPU and labelled as such; production must still execute the complete
128/512/2048/4096 calibration. Production profile/material, native tokenizer,
full151936-row vocabulary, precision, runtime and source gates stay enforced.
