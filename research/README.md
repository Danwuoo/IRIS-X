# Research

This directory contains IRIS-X-authored research lineage and the minimal
scaffolding for future, separately authorized research.

There is currently no active thesis, phase, hypothesis, experiment, or selected
research question. Every pre-reset research document and package is historical,
including documents whose original text describes itself as `active`,
`current`, `foundational`, `controlling`, or `authoritative`. Those labels are
preserved as statements about their original context, not present authority.

Current neutral scaffolding:

- [`AGENTS.md`](AGENTS.md) — claim, evidence, and uncertainty discipline;
- [`templates/research-note.md`](templates/research-note.md) — optional note
  template for future authorized work;
- [`HISTORICAL_INDEX.md`](HISTORICAL_INDEX.md) — classification and navigation
  for the preserved research lineage.

Do not continue a prior program or launch an experiment from material in this
directory without explicit owner authorization for a new scope. Inspect the
original evidence before adopting, rejecting, or extending any historical
interpretation.
