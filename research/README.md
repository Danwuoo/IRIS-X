# Conditional Research

Research is not the default production process. This directory is reserved for
explicitly authorized investigations prompted by repeated, unresolved product
engineering failures.

The owner opened Stage 4 ARC-AGI-2 research on 2026-10-05, targeting a score
above 85 on the official Kaggle evaluation. The
[research brief](stage4-arc-agi-2-research.json) defines four research workstreams,
the measured baseline, evidence limitations, and the required implementation
handoff. Research is assigned to the owner's dots cloud computer with Astra ultra;
local development uses GPT-6.1 Sol / xhigh. The owner relays cloud messages,
and the local controller reviews findings, dispatches implementation and
accepts the results. Existing consumed runtime identities remain frozen.

Historical IRIS-X research is available at its original paths from the
pre-product archive tag and has no current authority.
