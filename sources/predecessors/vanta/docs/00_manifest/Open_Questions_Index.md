# Open Questions Index

## Purpose

This manifest-level index routes open questions that are distributed across
manifest, specs, experiments, evaluation, and engineering documents.

It is not a decision log, gate inventory, schema authority, evaluation report,
or implementation order. Source documents keep their local question context.
This index classifies what each question is blocked by so follow-up work can
route to the correct layer.

## Status Vocabulary

| Status | Meaning |
| --- | --- |
| `Open` | The source question remains unresolved. |
| `Partially resolved` | A current gate or decision answers the first scope but leaves successor scope open. |
| `Resolved pointer` | A prior open question is answered by a decision or gate; do not reopen it here. |
| `Deferred` | The topic is intentionally outside current Stage 1 or post-Stage-1 planning scope. |
