# Historical Plans

All pre-reset plan and prompt documents in this directory are historical. They
were completed, retired, superseded, abandoned, or preserved as an operational
record. None is a current plan, and none authorizes a launch, relaunch,
collection turn, model/provider call, experiment, research phase, or
implementation.

The files remain at their original paths because historical experiments,
manifests, hashes, validators, handoffs, and evidence ledgers refer to those
paths and sometimes to their exact bytes. This directory-level classification
removes them from current authority without rewriting their contents.

Any future plan requires a new owner-authorized scope and a new document that
does not reuse a `TEMP_*` record as live instructions.
