# Product Documentation

`PRODUCT_THESIS.md` is the current product authority. P0 supplies two concise
policy documents:

- [`product-scope.md`](product-scope.md) defines what the product is intended to
  accomplish and which choices remain open;
- [`non-goals.md`](non-goals.md) defines what IRIS-X is not and prevents
  mechanism-led scope drift.

P0 defines no schemas, APIs, runtime behavior, or detailed architecture here.
Later product requirements and Domain Specification or Domain Package contracts
require an explicitly authorized scope.
