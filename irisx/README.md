# Historical IRIS-X Prototype

The `irisx/` package is preserved Phase 5 prototype code for immutable records,
execution ordering, evidence binding, policy/verifier interfaces, and terminal
adjudication. Historical experiment substrates and tests depend on it.

It is not the current IRIS-X architecture, a production SDK, or an automatically
approved starting point for future implementation. Its existing module
docstrings describe the prototype's original scope. Preserve it for
reproducibility; do not extend or promote it without explicit owner authorization
and fresh evidence.
