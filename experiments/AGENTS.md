# Experiments Zone

Use `experiments/` for explicit definitions, inputs, scripts, run manifests, reviewed results, and failure records. Separate definition, input, raw output, and interpretation; one does not establish another.

A result entry must identify corpus/source IDs, exact local paths, command or procedure, environment assumptions, time, cost/resource fields when relevant, and outcome including failures. Do not commit bulky transient outputs without an explicit owner decision.

Run repository checks before finalizing changes that affect registered paths or evidence.
