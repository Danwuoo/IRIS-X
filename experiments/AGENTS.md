# Experiments Zone

The existing contents of `experiments/` are preserved historical packages and
evidence. There is currently no active experiment. Do not run, extend,
regenerate, relocate, or reinterpret a package merely because its original
README describes an active batch or next step.

For any separately owner-authorized future experiment, keep explicit
definitions, inputs, scripts, run manifests, reviewed results, and failure
records here. Separate definition, input, raw output, and interpretation; one
does not establish another.

A result entry must identify corpus/source IDs, exact local paths, command or
procedure, environment assumptions, time, cost/resource fields when relevant,
and outcomes including failures. Preserve original bytes, hashes, terminal
records, and uncertainty. Do not commit bulky transient outputs without an
explicit owner decision.

Run repository checks before finalizing changes that affect registered paths or
evidence. New model/provider execution or a new experiment requires explicit
owner authorization; historical plans and packages grant none.
